# ui-style：工作台的视觉与排版

## 方向：editorial（纸感排版），不是 SaaS 仪表盘

- 底色奶油纸白 `#fafaf7`，正文墨黑 `#1a1a1a`，强调色芥黄 `#facc15`（少量、只给
  进度条/当前项/高亮标记）。
- 标题衬线（`Georgia, "Songti SC", serif`），正文系统栈
  （`-apple-system, "PingFang SC", sans-serif`）。中文字号 ≥16px，行高 ≥1.7。
- 层次靠**留白和字号**，不靠框套框。分隔用细线（`1px #e5e2da`），不用阴影卡片堆叠。

## AI 味黑名单（出现即返工）

- 紫蓝渐变、玻璃拟态、大圆角彩色卡片套卡片
- 彩底灰字 / 低对比度装饰字
- 每个标题配一个 emoji
- 英文 Inter/居中大标语式排版（这是中文工作页，不是 landing page）
- 无意义的图标网格、进度环仪表盘（进度用「7/23 条」+ 细进度条就够）

## 手机 webview 优先

- 单列。任何两栏结构在 390px 宽都会碎。
- 点击区 ≥44pt：勾选框做成整行可点，不是那个 16px 的小方块。
- 不横滑：长表格改成堆叠卡式条目；代码/长串 `overflow-wrap: anywhere`。
- 折叠用 `<details>`——原生、无 JS、状态语义清楚，正好承载「考场句 + 展开细节」两层。

## 板块骨架（参考，按需求定案增删）

顶部：标题 + 一句状态（「7/23 · 最近更新 08-28」）+ 细进度条
中部：各板块（`<details>` 折叠，重要的默认展开）
底部：自由笔记区 → 保存/导出/导入 → 更新记录（一行一版）
