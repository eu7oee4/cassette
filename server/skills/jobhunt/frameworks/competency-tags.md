# 能力标签词典 + 题型反查（story-mining 打标 / mock-interview 反查用）

两个用途：① 挖完故事给它**打标**；② 看到一道行为题，**反查**它在考哪个能力、
`stories/_index.md` 里哪些故事能打。标签统一用下面这十二个，别自造。

## 十二个标签

| 标签 | 它在考什么 | 中文面试官会怎么问 |
|---|---|---|
| **担责** | 主动扛下来、把事做完、对结果负责 | 「有没有做过职责之外的事」「一件你主动发起的事」 |
| **冲突处理** | 处理分歧、修复关系、达成一致 | 「和同事/导师意见不一致的时候」 |
| **影响力** | 没有职权也能推动、说服别人 | 「怎么说服别人接受你的方案」 |
| **跨团队协调** | 对上 / 对外 / 多方对齐 | 「几个人一起做事怎么分工、卡住怎么办」 |
| **处理模糊** | 信息不全、没人做过时怎么推进 | 「需求不清楚的时候你怎么开始」 |
| **领导力** | 带人、定方向、补位 | 「带过团队吗，遇到不配合的怎么办」 |
| **成长心态** | 复盘、从反馈和失败里学 | 「最大的失败」「被批评过什么」 |
| **结果驱动** | 高标准、抗压、把结果做出来 | 「一件很难但你做成了的事」「deadline 很紧的时候」 |
| **数据决策** | 用事实和数据做判断 | 「一次靠数据改变结论的决定」 |
| **用户导向** | 从用户出发、为用户取舍 | 「怎么判断一个功能该不该做」 |
| **行动与创新** | 快速试错、果断动手、想出新解法 | 「一个不走寻常路的方案」 |
| **抗挫** | 犯错、失败、挫折后的恢复 | 「一次你搞砸的事，后来怎么样了」 |

产品岗最常考的是**用户导向、处理模糊、数据决策、影响力**四个；技术岗偏**结果驱动、
数据决策、成长心态**。解码时从隐藏信号能推出这家会重点考哪几个（jd-signals.md）。

## 反查用法（拿到一道题）

1. 题 → 上表对应到 1–2 个标签。
2. 去 `stories/_index.md` 找带这些标签的故事。
3. 命中多个 → 选信号最强、最有取舍、跟目标公司最搭的那个。
4. 全未命中 → 记「待挖」，转 story-mining。**不在模拟面试或手册里现场编故事。**

## 打标纪律

- 一个故事**主标 1 个 + 副标 1–2 个**。贴满 = 没重点。
- 主标 = 这个故事最无可争议的信号；副标 = 换个开场句也能打的方向（见 star-car.md 一稿多用）。
- 失败类故事几乎都同时带**成长心态**，记得加。
- `_index.md` 每行的「能答哪几类题」改成这个写法：`主标：处理模糊；副标：数据决策、成长心态`。
  存量两条（sdk-forge-continuity、scene-merge-question）一起补标——补之前先给机主看。
